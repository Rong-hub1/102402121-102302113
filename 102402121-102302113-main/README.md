# 校园失物招领

一个基于纯前端（HTML + CSS + JavaScript）实现的**校园失物招领** Web 应用。用户可以发布寻物 / 招领信息、集中浏览、按关键词搜索、查看详情与联系方式，并在物品找回 / 归还后标记状态为「已完成」。

无需服务器、无需安装任何依赖，用**谷歌浏览器直接打开 `index.html`** 即可运行。

---

## 一、功能清单

| 功能 | 说明 |
|---|---|
| 首页浏览 | 信息卡片按时间倒序展示，支持「全部 / 寻物 / 招领」类型切换 |
| 分类筛选 | 顶部 chips 按物品分类（证件卡片、电子产品、钥匙、雨具等）筛选 |
| 关键词搜索 | 按物品名称 / 描述 / 地点搜索，命中关键词高亮显示 |
| 发布信息 | 选择「寻物」或「招领」，填写表单发布，含必填校验 |
| 查看详情 | 点击卡片进入详情页，查看地点、时间、描述、联系方式，浏览量 +1 |
| 复制联系方式 | 详情页一键复制发布者联系方式（附加功能） |
| 我的发布 | 查看全部本地发布，统计进行中 / 已完成数量 |
| 状态管理 | 发布者可标记「已找回 / 已归还」，完成后他人不再被误导联系 |
| 本地持久化 | 数据保存在浏览器 localStorage，刷新不丢失 |

> 本次作业不实现后台管理、实名认证、即时聊天、地图定位等复杂功能。

## 二、目录结构说明

```
第四次作业/
├── index.html          # 主页面（SPA 单页应用入口）
├── README.md           # 本说明文档
├── css/
│   └── style.css       # 全部样式（手机框居中 + 绿色主题）
├── js/
│   ├── store.js        # 数据层：纯函数（校验/搜索/筛选/高亮/状态/持久化），可被单元测试直接调用
│   ├── seed.js         # 首次访问时的示例数据（种子）
│   └── app.js          # 应用层：SPA 路由、页面渲染、事件绑定
└── test/
    └── test.html       # 单元测试页（浏览器内自动运行，36 个用例）
```

**设计思路**：将「数据逻辑」与「界面逻辑」分离。`store.js` 只做纯数据处理、不碰 DOM，因此可以脱离界面独立测试；`app.js` 负责把数据渲染成界面并响应用户操作。这样分层既便于单元测试，也降低了耦合。

## 三、使用说明（如何运行）

### 方式一：直接打开

1. 下载本项目全部文件，保持目录结构不变；
2. 用**谷歌浏览器（Chrome）**双击打开 `index.html`；
3. 即可看到手机框样式的应用界面，所有功能立即可用。

> 数据保存在当前浏览器的 localStorage 中，同一浏览器刷新 / 关闭后仍在；清除浏览器数据或换浏览器会重置为示例数据。

### 方式二：本地服务器

若直接打开遇到本地文件限制，可在项目根目录启动一个静态服务器：

```bash
# Python 3
python -m http.server 8000
```

然后用谷歌浏览器访问 `http://localhost:8000/index.html`。

## 四、单元测试说明

打开 `test/test.html`（用谷歌浏览器），页面会**自动运行全部测试**并在顶部显示汇总结果（绿色 = 全部通过，红色 = 存在失败）。

- 测试对象：`js/store.js` 的纯函数
- 用例数：36 个，分 8 组（数据校验、创建条目、搜索、筛选、高亮与 XSS 防护、相对时间、状态变更、持久化）
- 测试方法：白盒为主，覆盖正常路径、边界值（空字符串、全空格）、异常输入（非法 type、非数组）、安全（XSS 转义）
- 无需安装任何环境，打开即跑，可随时回归
