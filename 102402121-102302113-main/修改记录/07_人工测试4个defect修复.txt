【defect2】 二级分类横向排列显示不全，无法左右拖拽
════════════════════════════════════════════════════════

  问题描述：
    首页 typeTabs 和 filter-bar（分类 chip）内容过长时，
    右侧被截断无法看到，也无法左右滚动。

  修改文件：css/style.css

  --- typeTabs ---
  修改前（flex:1 等分，永远不会溢出）：
    .tabs { display: flex; ... }
    .tab { flex: 1; padding: 10px 0; ... }

  修改后（固定内容宽度 + 横向滚动 + iOS 平滑回弹）：
    .tabs {
      display: flex;
      overflow-x: auto;
      -webkit-overflow-scrolling: touch;   ← iOS 惯性滚动
    }
    .tabs::-webkit-scrollbar { display: none; }
    .tab {
      flex-shrink: 0;    ← 关键！不被压缩
      min-width: 70px;
      padding: 10px 14px;
    }

  --- filter-bar ---
  修改前：overflow-x:auto 但缺少平滑滚动

  修改后：加了 -webkit-overflow-scrolling: touch;
         原有的 chip { flex-shrink: 0 } 保持不变

  --- 补充：第二次修复（用户反馈 chip 行仍不能滚） ---
  原因：CSS 虽然有 overflow-x:auto 但滚动条被隐藏了，
        PC 用户既没触摸板手势也看不到滚动条，无法滚动。
  修复：
  (a) app.js bindEvents 里新增 enableDragScroll 通用函数
      用 mousedown/mousemove/mouseup 实现 PC 端拖拽滚动；
      同时在移动时阻止 click 冒泡，避免"拖拽后误触发 chip 点击"
  (b) style.css 给 .tabs 和 .filter-bar 加 cursor: grab / grabbing
      提示用户可以拖拽

  enableDragScroll 代码片段（app.js 约第 354 行）：
    function enableDragScroll(el) {
      var isDown = false, startX = 0, scrollLeft = 0, moved = false;
      el.addEventListener('mousedown', function (e) {
        isDown = true; moved = false;
        startX = e.pageX - el.offsetLeft;
        scrollLeft = el.scrollLeft;
      });
      el.addEventListener('mousemove', function (e) {
        if (!isDown) return;
        e.preventDefault(); moved = true;
        var x = e.pageX - el.offsetLeft;
        el.scrollLeft = scrollLeft - (x - startX) * 1.5;
      });
      // 拖拽后阻止 click 冒泡
      el.addEventListener('click', function (e) {
        if (moved) { e.stopPropagation(); e.preventDefault(); }
      }, true);
    }
    enableDragScroll($('typeTabs'));
    enableDragScroll($('categoryChips'));

    用户搜"寻物""招领"（type）、搜时间字符串都找不到。

  修改文件：js/store.js —— searchItems 函数

  修改前：

      .join(' ').toLowerCase();

      it.title,

      it.location,
      it.category,
      it.time,                                    ← 新增：丢失/拾获时间

  (b) store.js searchItems：
